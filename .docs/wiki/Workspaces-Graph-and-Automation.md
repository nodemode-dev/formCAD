# The graph and automation

**The graph.** A node editor with data trees, about 185 nodes, preview and bake, loops and an optimizer. Commands `graph`, `graphrun`, `graphbake`; headless with `formcad-engine graph run`. File format: `docs/GRAPH_FORMAT.md`. Writing nodes: `docs/NODE_SDK.md`.

**Automation.** LISP (`lisp`, `appload`), scripts (`script`, `rscript`), macros (`macrorecord`, `macroplay`), plugins (`plugins`, `pluginenable`), the CLI and MCP. The trust rules are on [[Automation-and-Agents]].

See manual chapters 5 and 13.
